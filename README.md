# To-Do List App

A responsive and user-friendly To-Do List web application built using **HTML, CSS, and JavaScript**. The application allows users to add, complete, and delete tasks while automatically saving tasks using browser Local Storage.

## 🚀 Features

* Add new tasks
* Mark tasks as completed
* Delete individual tasks
* Clear completed tasks
* Display remaining task count
* Add tasks using the Enter key
* Tasks remain saved after refreshing the page
* Responsive and mobile-friendly design
* Clean and simple user interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Interactive functionality and task management
* **Local Storage** – Saving tasks in the browser

## 📌 How It Works

Users can enter a task in the input field and click the **Add Task** button to create a new task.

Each task can be:

* Marked as completed using the checkbox
* Deleted using the Delete button
* Removed automatically from the active task count when completed

The application uses **Local Storage** to save tasks, allowing them to remain available even after refreshing or reopening the browser.
